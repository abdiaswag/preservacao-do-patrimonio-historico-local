# Preservação do Patrimônio Histórico Local

Projeto Integrador (PI) desenvolvido para a disciplina de Programação para Internet do IFRN Campus Parnamirim.

## Sobre o Projeto
O projeto **Preservação do Patrimônio Histórico Local** é uma aplicação web focada no resgate e valorização do patrimônio histórico e cultural da cidade de Parnamirim/RN. A plataforma apresenta fatos históricos sobre marcos locais, como a Base Aérea (Trampolim da Vitória) e o Centro de Lançamento da Barreira do Inferno, além de contar com um Quiz cultural interativo.

## Tecnologias Utilizadas
- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização, layout responsivo e design visual.
- **JavaScript (ES6)**: Manipulação do DOM e lógica da interatividade do Quiz.
